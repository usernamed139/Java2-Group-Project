Our group project is a Java fire simulation. One "Fire" tile starts at the center of the board and spreads out through a forest. The forest is populated with wood, dry wood, and water (which does not burn). When wood is next to fire, there's a chance that it turns into fire or resists burning. Dry wood is more likely to turn into fire. After a certain amount of ticks, fire stops burning and turns into ash. The user can start and stop the simulation using GUI buttons.
